Third-party data in assets/
=========================

assets/seti.json is generated (examples/gen_seti.rs) from Visual Studio Code's
extensions/theme-seti/icons/vs-seti-icon-theme.json and the language contributions
of VS Code's built-in extensions. assets/vscode_dark_defaults.json holds dark
colour defaults from VS Code's colour registry and extensions/git/package.json.
Both come from the open-source VS Code repository (https://github.com/microsoft/vscode;
those extensions declare "license": "MIT"), under the licence below. The icon
theme itself is based on Seti UI, whose notice follows.
